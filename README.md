# TIES – Tactical Intelligence Explainability System

אב-טיפוס (MVP) למערכת הנגשת מודיעין והסברתיות טקטית: השוואת חלופות ציר תנועה עם הסבר שקוף ("למה?") לכל סיכון, לפי רמת הסבירות ואמינות המקור.

> כל הנתונים במערכת **מדומים** (תרחיש הדגמה מבצע "חומת אש"). אין חיבור לשום מערכת אמיתית.

## הרצה
פותחים את `index.html` בדפדפן – אין צורך בשרת, התקנה או חיבור לאינטרנט.

## מרחבי פעולה
בראש המסך בוחרים מרחב:
- **תרחיש סכמטי – ״חומת אש״**: מפת רשת מדומה.
- **חאן יונס – מרכז העיר (מפה אמיתית)**: רחובות ומבנים אמיתיים מ-OpenStreetMap (נשמרים מקומית ב-`data/khan-younis.js`, עובד גם אופליין). אפשר להוסיף רקע תצלום לוויין (דורש אינטרנט). **נתוני האיום על המפה מדומים לחלוטין.**

מפה: © OpenStreetMap contributors (ODbL).

## יכולות ה-MVP
- **דקירת מוצא ויעד** על גבי מפת גזרה סכמטית (תא = 20 מ׳).
- **שתי חלופות ציר** (מהיר / מוגן) + מטריצת השוואה: זמן, מרחק, איום מרכזי, אמינות מקור, סיכון משוקלל, דרישת משאבים והמלצה.
- **כרטיסיית הסברתיות** לכל ציר: סבירות, אמינות, עדכניות ו-3 נימוקים לכל איום; הקצאת קנים לחיפוי וזיכוי הנדסי כאמצעי מיתון.
- **שער אישור קמ״ן** (Human-in-the-Loop) לפני הפצת הצירים.
- **משוב שטח בלחיצה אחת** בסוף כל מקטע (ציר נקי / אומת חשד / בוצע מעקף / נתקלנו).
- **Offline-First + Delta Sync** – שמירה מקומית ושליחת שינויים בלבד בחידוש קשר (מדומה).
- **תחקיר ולמידה** – עדכון בייסיאני של אמינות אינדיקטורים וסוגי מקור לפי דיווחי השטח.
- סינון אינדיקציות לא רלוונטיות (מחוץ למרחב, פג תוקף, כפילות, ללא תוכן) וקליטת ידיעה חיה.

## מחוץ לתחום
הצפנה אמיתית, שרת, אינטגרציה למערכות שו״ב, מפות אמיתיות ועיבוד וידאו.
